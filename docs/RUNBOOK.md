# 产线调度值班操作

交班时先打开产率与入仓单，记下页尾运行指纹。需要调整处置量时，在工作台输入已确认的仓位分配限额（吨），查看变更后的产率与入仓单，再从「地磅与验收证据」核对相关环节。

交班时展开「产率拟合」核对每种材质的估法：`材质独立` 是默认，`共用历史` 只在该材质最近五个作业日回测的出料公斤绝对误差之和严格下降、且没有漏估、没有在用产线缺样本、没有新增下界失守批次时才启用。若某材质显示「共用历史」，当班的分级下界与清料预留都按该估法给出，抽检或地磅侧出现异常时优先回看这条依据。

没有加载到样例时，先检查 `/health`。若健康接口已恢复，刷新页面并重新提交本班额度。输入超限会得到 `INVALID_SCENARIO`，页面保留上一次有效结果。

复核记录可通过工作台下载。导出包含前台展示的全部批次结果及六个环节的证据，便于按运行指纹对照。
