# 再生料班次契约

磅单保留原编号，时间以 UTC 处理。吨转换为公斤后只允许整数。计量坏行、重复扫描、晚到更正、同版冲突各自归因。料批的材质与产线须一致才能进入取样。

抽检上中下三个层位。各层按称样重量加权，跨层采用等权。Wilson 上界是调度参考提示。每个切片的等效样本数取 10，现场部署需按抽样方案估计有效样本数。无取样或缺层影响放行。

按材料拟合岭回归，特征为入料量对数、杂质比例、水分比例与涡电流线标识。训练统计来自已关账的历史折，估值界为留出误差的保守分位。严重超出历史支持时输出留样复验。

## 当班产率估法

每种材质在两种估法间取一：`材质独立` 只用该材质自己的历史，`共用历史` 把各材质样本汇入同一条回归但保留材质标签，从而在样本稀疏时借他材质的数据。默认 `材质独立`。

估法用当班已关账记录中最近五个作业日回测。回测样本不进入两种估法的训练或校准：两种曲线只用回测窗口首个作业日之前的记录拟合，截点后未成熟的历史折也不参与。

逐材质按以下顺序裁决，任一条命中即沿用 `材质独立`：

1. 任一候选估法漏估回测批（缺曲线或料批超出训练支撑）。
2. 该材质任一条在用产线在回测窗口内缺样本。
3. `共用历史` 在任一条在用产线上"实产低于下界"的批次多于 `材质独立`。规则 2 已保证每条在用产线都有样本，所以这里的比较逐线进行。

三条都不命中时，只有该材质的出料公斤绝对误差之和严格下降才切到 `共用历史`；持平保留原估法。误差按回测批的实际出料公斤 `round(expm1(入料量对数))` 加权，比较的是产率绝对误差乘该公斤数。

选中的估法用于当班分级与清料仓位预留：产率、下界、上界与干净物料的预留公斤数都由该材质的在用曲线给出，未切换的材质仍用 `材质独立` 曲线。选择依据、回测窗口、两种估法的误差和与下界失守批数随「产率拟合」环节导出一并提供。

干净物料依据保守产率下界预留公斤数。同材质仓位采用可完整容纳的最小剩余空间优先。班次限额按 1 吨计。预留、未分配预计出料与预计残渣之和应等于地磅净重，逐批和逐仓核对。

## 环节分组诊断

每个环节公开分组、风险方向与阈值、有效观测数、缺测数和命中的凭证。只有有限数值计入诊断，等于阈值的记录保持正常。相关证据计数与明细逐项守恒。诊断随 API 和证据导出提供。
